# 万事通

手机上用的全能 AI 助理（网页 App，可加到主屏幕）。

- 聊天：可切换 460 多个模型，默认 Meta Muse Spark 1.3，也有 Claude、GPT、Gemini、DeepSeek、通义千问等
- 语音：讲话打字、免手持语音对话、AI 真人声朗读
- 看图读文件：拍照、相册、PDF（含扫描件）、Word、Excel
- 画图：叫它画就会画，附上照片可以改图
- 上网：需要最新资料时自己上网查，附来源
- 多 AI 会诊：同时问几个 AI，再综合成一个答案

AI 服务经由 [OpenRouter](https://openrouter.ai)。钥匙只存在你自己的手机里，这个网站不收集任何资料；对话也只存在手机里。

第三方组件：marked、DOMPurify、pdf.js、mammoth、SheetJS（许可证见 `vendor/`）。
